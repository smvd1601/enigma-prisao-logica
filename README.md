# Enigma — A Prisão Lógica (Python)

Jogo digital de lógica proposicional feito em **Python 3 + Tkinter**.

## Como executar
1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python3 main.py
```

No Windows, também pode funcionar com:

```bash
py main.py
```

Não é necessário instalar bibliotecas externas: o Tkinter normalmente acompanha a instalação do Python.

## Como jogar
- De 2 a 5 jogadores no mesmo computador.
- Cada jogador começa com 3 vidas.
- Na sua vez, lance o dado e avance pelo tabuleiro.
- Responda aos desafios de lógica proposicional.
- Resposta correta concede uma chave; resposta errada tira uma vida.
- As portas exigem chaves e a saída exige 2 chaves e o acerto do desafio final.

## Conteúdos de lógica
- Conjunção (∧)
- Disjunção (∨)
- Negação (¬)
- Condicional (→)
- Bicondicional (↔)
- Expressões compostas
